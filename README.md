# Portafolio de Técnicas Estadísticas y Modelación

## Descripción

Este repositorio contiene una recopilación de prácticas, ejercicios, proyectos e introducciones desarrollados durante el semestre en el curso de técnicas estadísticas y modelación utilizando R y RStudio.

El objetivo principal del curso fue aplicar diferentes modelos estadísticos y matemáticos para el análisis de datos, interpretación de resultados y simulación de fenómenos mediante herramientas computacionales.

## Contenido del repositorio

El portafolio está organizado por temas, incluyendo scripts, bases de datos y resultados obtenidos en cada práctica y proyecto.

### Temas incluidos

- Introducción
- Modelo de regresión lineal
- Regresión de Poisson
- Regresión logística
- Regresión multinomial
- Ecuaciones diferenciales
- Modelos de redes
- Series de tiempo
- Proyectos

## Estructura

Cada carpeta contiene:

- Scripts en R (`.R`, `.Rmd` o `.qmd`)
- Bases de datos utilizadas (`.csv`)

## Herramientas utilizadas

- R
- RStudio
- GitHub

## Objetivo del portafolio

Este repositorio funciona como evidencia del trabajo práctico realizado a lo largo del semestre, mostrando la implementación de distintos modelos estadísticos y técnicas de análisis de datos.
